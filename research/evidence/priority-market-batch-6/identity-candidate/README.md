competition. Never replace another pending ledger wholesale, reset it, or mint
new IDs for the same sites. Historical simulation UUIDs are not these IDs.

UTF-8 JSON (sorted keys, compact separators, unescaped Unicode), without a trailing
newline. `artifact-byte-hashes.json` separately hashes exact public file bytes.

Source originals/full extractions remain in ignored private `work/`. The public
evidence-version file contains custody metadata and component hashes only.
