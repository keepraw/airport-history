## 完整机器筛选与研究范围

没有重新扫描全球 Git 历史或重建原索引。本轮实际遍历现有 1,240,058 条来源修订、117,356 个已选候选、全部 88,330 个事件组、2,484 个代码关联候选（IATA 2,012、ICAO 472）、493 条地理复用线索及 86,950 条参考记录；同时读取既有跨来源代码索引和研究挂接。原基线的 992,488 条合并变化线索保持原定义。代码关联候选覆盖 168 个国家或地区；全部事件组的国家／地区字段覆盖 245 个代码，两者分母不同。

## 准入与版权边界

[统一来源家族提案](policy/README.zh-CN.md)及 [proposal.json](policy/proposal.json)覆盖 48 个国家／发行机构家族，保持 **proposal-only**；不要求逐机场审批。IATA、ICAO 分别定义可接受原件、时间连续性、独立性、冲突及使用条件。公开访问、可复用事实／必要短引文依据和项目准入授权是独立条件；Owner 不能授予第三方版权。没有把中国物理身份授权扩展为代码授权，没有扩大 AAI／韩国范围，没有恢复 PR #32 系统或修改 PR #29。

AAI 的既有固定输入结构在临时的已发布基线 checkout 中以[十三个仅含数据的快照](policy/aai-intake/replay-manifest.json)恢复，随后调用**同一个未修改的原准入 CLI**。这是原有数据路径的隔离重放，不是新审批引擎或国家 Executor。真实准备阶段重放私有原件；离线 CI 明确只重放其收据。旧研究、政策、授权、绑定执行器和历史归档检查保持不变；中国 0.11.0 的原身份准入先按旧字节重放。完整记录见 [0.12.0 准入包](../../admissions/0.12.0/README.md)。

## 剩余队列与继续顺序

机器筛选已处理全部现有候选。高价值组中 64 个完成主要证据研究，**1,134 个尚未完成该级别的证据研究**；其中相关目录别名已经挂接现有研究的情况单独标记，不额外计为独立完成。69 个高价值组已开展调查，包含上述 5 个受阻／仅目录组。所有 1,198 个高价值组继续出现在[带进度的后续队列](remaining-high-value-queue.jsonl.gz)，区分待合并、证据后续、相关观察复用、受阻和未取证。

下一波按该队列和来源聚类推进：优先取得明确代码通知、受控 AIP 修订链及可用权利材料；补全多国 IATA 边界事实的原件保管链与执行证据；处理 VOMY 等竞争场址并拒绝仅凭坐标变化裁决迁址。每个已调查事件的具体缺件与下一动作在地区 `assessments.json` 中，未调查组的缺件保留在全量排名及后续队列。一个国家受阻不会阻止其他符合条件市场继续研究。
