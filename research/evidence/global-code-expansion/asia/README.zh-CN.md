# 亚洲首轮代码证据研究

本包按完整全球排名核对29个研究案例、29个主要事件组，涉及13个国家或地区、49个具名物理机场研究目标。目标名单包括访问受阻和身份未解决的场址，不等于49个已核实机场。25个主要事件组属于最终机器排名的高价值层；其中23个实际检查了官方或承运人原件收据和引用，另1个仅有目录证据、1个官方原件取得失败。4个案例属于后续层，独立列出，不用来补足高价值研究数量。

`assessments.json` 每个案例只计一个主要事件组。`relatedEventGroupIds` 是同国同码检索关联，供后续导航，不表示这些组都已独立调查或证明属于同一事件。IATA 与 ICAO、代码生效、机场启用、停航、物理关闭、原件发布日期、受控版本日期和抓取时间始终分开。

## 可提交给现有准入路径的实际代码成果

印度 AAI 的两个受控版本（2026-06-11、2026-07-09）分别将 VOSH、VEAY、VANM 关联到明确的机场名称和相同 ARP。每个代码有两个不同原件、相隔28天，且参考索引为一个匹配和一个位置。按未修改的 AAI 授权规则，仅提出区间 `[2026-06-12, 2026-07-09)` 的27个完整本地日期，保留首次分配和最终撤销边界未知。三条 ICAO 关系合计潜在81个 resolved 代码日期查询；正式准入及实际差分以统一发布包为准。本研究包中的 `claims.json` 保持 pending，不冒充正式数据。

VOMY 同样取得两个 AD 2 原件，但目录有三个位置假设。未将坐标差异自动判为迁址或纠错，继续按既有规则升级审查。AAI 的身份和 ICAO 范围不延伸到 IATA，也不延伸到其他发行机构。

本轮新取得 Manas 运营商公告及带 IATA 名称和署名的2025-05-09通知 PDF。两者明确提到 FRU 改为 BSZ，拟于2025-08-09生效。PDF 来自第三方 AKI 镜像，尚缺发行机构原站真实性、通知替代生命周期和实际实施核验；`boundary-facts.json` 只保留候选边界事实，不建立连续有效期，也不制造 resolved。二手报道的8月11日不取代原件明确的8月9日。

Techo 新运营商原件补强 KTI 与新场址、实际运营迁转的关联，但运营日期不当作代码分配日期；既有正式 KTI 不重复计为成果。日本 JMA 气象报文切换、韩国指定范围、旧机场停航与未来 CAAC 规范均保留各自语义，不借用为其他命名空间的有效期。

## 原件、来源使用权和重用

本轮取得17个不同原始字节流：AAI 12份、CAAT 2份、Kyrgyzstan 运营商1份、IATA 通知镜像1份、Techo 运营商1份。每份都保留原始、提取和规范化文本 SHA-256、发行或来源身份、访问结果及日期性质。完整原件、完整提取文本留在 ignored `work/`；公开包只含元数据和最少必要引用。五个来源家族不等于五个独立事实证明者，同一机构不同版本和转载镜像不增加独立出版者数量。

另对70条既有来源收据作离线重用，记录原锁文件、源记录、已有引用和 catalog 的哈希。历史缺失的提取哈希仍为 null，不声称本轮重新取得或重放了旧原始字节。失败、空响应、拒绝访问页面也明确保留：HTTP 200 拒绝页面不算原件，搜索摘要不算已经取得的官方资料。公开访问不等于取得完整文件、图表或数据库的再分发许可。

本包未激活全球来源家族授权，未改变 AAI/KR 授权，未把中国物理身份授权解释为代码授权。17份新原件的三种哈希，以及全部可取得的旧锁、源记录、catalog 和引用哈希均已在本地核验。
