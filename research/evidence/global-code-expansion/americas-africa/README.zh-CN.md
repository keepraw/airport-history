# 美洲、非洲与大洋洲：首轮全球代码研究

本轮实际审查 29 个规范事件组，覆盖 16 个国家或地区。其中 20 个最终高价值事件组完成新增原件或既有锁定证据的实质审查，对应 20 个不同的取证聚类；1 个高价值组因访问与使用权条件受阻。另有 8 个低于全球高价值阈值的补充调查。相关别名组只作交叉索引，不重复计数。`assessments.json` 保留全球排名、物理机场、代码、逐组判断与下一步。

新增直接代码事实来自 Palm Beach County 机场运营商 FAQ：ICAO 从 KPBI 改为 KDJT 的日期为 2026-07-09，IATA 从 PBI 改为 DJT 的日期为 2026-08-18。县政府页面核对发布者身份，FAA 周期 2611 原始 XML 与 AL-449 机场图交叉验证当前 ICAO 标识和具体物理场址。图上的 DJT 本地标识不被解释为 IATA 证据。

四条边界候选保留未知外边界，仍为 pending。FAQ 的代码变更日期不会被扩展为无期限连续历史。另一个独立文件只提出 FAA 受控版本完整当地日期窗口 2026-10-30 至 2026-11-26（不含末日）的条件场景；它明确披露日期运算时区，并仍缺来源家族政策、NOTAM 生命周期和相关使用权审查，**不属于证据齐备的模拟白名单**。本区域新增正式 IATA、ICAO 分配、正式 resolved 查询、已解决跨场址复用及 uncertain 缩减均为 0。

ASECNA 的科特迪瓦、马里、刚果、加蓬和塞内加尔原件、南非 ATNS AD 2、巴西 DECEA AISWEB、加拿大 NAV CANADA 通知、格陵兰及其他运营商资料得到批量复用。它们为候选提供代码与场址观察、迁建背景或关闭事实；这些事实均不代替代码有效边界。Austin、Williston、Chaitén 等既有原件的锁定记录与最小引用离线复用，没有用多年相隔的目录观察拼造连续有效期。

Airservices Australia 返回的版权同意页不等同于取得 ERSA 原件；未接受同意条件，也未绕过访问限制。Guinea ANAC 及其他不可用原件保留真实失败记录。所有新取得的完整原件、完整提取文本和规范化文本只留在 ignored `work/`，公开内容限哈希、来源元数据、最小事实锚点与原创分析。不同版本及镜像不增加发行机构独立性。

有一次已披露的重复获取：FAA 2611 XML 后来发现已锁定于 `global-batch-5` 的 `b5-us-dtpp-2611`。原始 SHA-256 完全一致，已从新增原件数及独立证据数中排除；不将此获取描述为新来源。后续获取先检查既有 URL 锁。其余新的原始字节哈希已与旧锁比较，未发现重复。

来源、实际访问结果及三类 SHA-256 见 `source-acquisition.json`；既有原件复用及缺失旧哈希限制见 `reused-evidence.json`。每个事件的后续任务明确区分所需 IATA 通知、ICAO AD 2／修订／NOTAM、场址交叉验证和来源家族授权，不要求逐机场审批。
